ORAL DENT — VERSION 3.2

CAMBIO PRINCIPAL V3.2

- La ubicación visual de ORAL DENT fue reubicada al otro lado de Av. Alameda Sur,
  más próxima a la intersección con Los Olivos, siguiendo la referencia indicada.

El mapa y la dirección son material de demostración. Antes de publicar la web,
la ubicación exacta deberá ser confirmada por el consultorio.

Para probar:
1. Abra index.html en Chrome, Edge o cualquier navegador moderno.
2. No requiere instalación ni servidor para esta demostración local.
